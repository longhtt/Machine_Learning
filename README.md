# Machine Learning Course Workspace

This repository contains coursework, activities, labs, discussions, and quiz materials for **CPSC 5310: Machine Learning**.

## Repository structure

- `In-Class_Activity/`  
  Timed and practice classroom activities (Act1, Act2, Act3, Act4, Act6, Act8), mostly Jupyter notebooks.
- `Exercises/`  
  Weekly homework-style exercises and notebooks (`EX1`–`EX10`) covering core machine learning topics and exercises.
- `labs/`  
  Hands-on lab notebooks and associated datasets/figures.
- `Reading_and_Essays/`  
  Reading-response style work and notebook writeups.
- `GuidedDiscussion/`  
  Discussion prompts and interactive notebooks.
- `Quiz/`  
  Quiz notebooks and materials.

## How to use

1. Install Python and Jupyter-related tooling (for example Anaconda, Miniforge, or `pip` + `venv`).
2. From the repository root, start Jupyter:
   - `jupyter notebook`
   - or `jupyter lab`
3. Open the notebook corresponding to the assignment/activity you want to run.
4. Run cells in order and save outputs as you complete each prompt.
